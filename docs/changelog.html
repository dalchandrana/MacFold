v0.1.12 Latest Release
Release on GitHub →

Ghost Perspective Compensation & In-App Updater

Introduces the new Ghost effect with resting-plane perspective ray compensation, an automatic in-app updater with SHA-256 validation, and bounded texture memory reclamation.

  • Ghost Effect: Intersects a stationary viewer's ray through the tilted panel with the last resting desktop plane. Tracks counter-rotation faster than optical softening.
  • In-App Updater: User-initiated GitHub release checks via HTTPS with SHA-256 verification and atomic binary swap into Applications.
  • Memory Safety: Stopped effects immediately release their blur pyramid, imported capture textures, and drawables back to the OS.
  • Late-Blur Spans: Small lid movements stay gentle even at low angles with a minimum 20° geometry span.

Background Capture Continuity

Preserves active lid following across macOS Spaces and virtual desktops without raising settings windows.
